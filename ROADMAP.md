# GameForge learning roadmap

GameForge teaches a complete small-game workflow in manageable paths. The current release contains C# foundations and a console RPG project. Other paths are planned, not available lessons.

## Release order

1. Finish and playtest C# foundations: 18 lessons, both exercises per lesson, followed by an optional console RPG. Unlock the full-course feedback review after all 18 lessons; the project is not required.
2. Unity basics: introduce the editor, scenes, GameObjects, components, transforms, C# scripting, movement, collision, UI, and a playable build. Start with simple shapes and explain Unity's lifecycle separately from console programs.
3. Krita game art: introduce the canvas, layers, colors, sprites, transparency, and export. Make a character and items for a small 2D Unity game.
4. Blender foundations: introduce navigation, transforms, mesh editing, low-poly props, materials, UV mapping, and export. Build a treasure chest.
5. Shared 3D project: paint the chest's texture in Krita, import its model and texture into Unity, add interaction and loot in C#, add sound, test, and build.

Teach game design, sound, accessibility, optimization, asset licensing, version control, and playtesting within projects, then expand into dedicated paths as needed. Art paths should remain usable by learners who are not taking the programming path.

## Lesson and platform requirements

- Give each path and lesson stable IDs so updates preserve progress. Keep prerequisite links, learning goals, illustrated walkthroughs, expected results, practice, hints, and project checks.
- Record the application version used for each tool lesson. Test instructions in that version before marking the lesson available. Use official installation links.
- Unity, Blender, and Krita run locally. Browser lessons track progress and explain tasks; they do not execute uploaded code or launch tools automatically.
- Initially accept feedback locally and show first-party examples. Any later community publishing needs moderation, reporting, licensing, and explicit file-type rules. Do not accept arbitrary executable uploads.
- Full-course feedback is a learner convenience gate based on local progress, not proof of identity or a tamper-proof credential. It requires all current C# quizzes and code blanks and remains locked for incomplete or malformed progress.

## Next release milestone

Publish a reviewed C# preview for a friend to finish at their own pace, collect feedback after the entire foundations course, improve the teaching, then author and verify the first Unity lessons.
