# C# foundations initial test

Target: 10 modules, 39 lessons, from first statements to a tested console RPG. Existing lesson IDs and answers remain stable. Each added lesson includes a glossary, value trace, explained output, quiz with choice-specific feedback, text-only code blank, and optional lab.

Modules 6–10: organize code and handle failures; protect data and express rules; inheritance, interfaces, and composition; save data and test rules; finish and playtest the RPG. These are foundations for console C#, not a claim to cover all of C# or Unity.

Quality gates: website tests and build; compile and execute first-party lesson, lab, bug, repaired, and lab-variation samples; actual-browser navigation and module-boundary checks; Claude review at the completed-course milestone. User code remains text only.

Initial test: use the same browser and address throughout. Work through the course at your own pace; note lesson IDs, first confusing words, unclear hints, and navigation issues. Finish both exercises in every lesson to unlock the full-course review. Optional labs and the console RPG do not block the teaching review.

Friend test: after the initial test, prepare a hosted preview link. localhost only reaches the computer running the server. Ask the friend to start in their own browser, think aloud during the call, and describe expectations before clicking. Avoid giving answers immediately. Record assistance, confusion, and reproducible bugs without personal details. Copy the local feedback report at the end. Do not reset progress unless the learner wants a fresh run.

Review priorities: incorrect teaching or answers, lost work, inaccessible controls, unclear explanations, then visual refinements. Review the findings before expanding into Unity or art courses.
