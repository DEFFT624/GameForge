BEFORE YOU BEGIN

A few things to know

Do I have to install anything?

No. You can read lessons, answer quizzes, and fill code blanks in your browser. To compile C# or build the project, you will need a separate local setup; the First steps guide links to Microsoft’s instructions.

Is my progress shared with other people?

No. Everyone sees the same lessons, but answers, progress, and saved snippet drafts stay in this browser. Clearing browser data removes them. There are no public accounts or submissions in this test build.

Can I listen to my own music?

Yes. Quest Radio lives in the learning workspace. Choose local songs and press Play. Music continues between lessons, and files are never uploaded. Refreshing or leaving the workspace clears the playlist.

Will this run code I paste?

No. Examples and drafts are text only. Code blanks check a small expected answer; they are not a compiler. There are no executable uploads.
