# Focused learning design

Editable Figma reference: https://www.figma.com/design/4ZgeUF6ZnUNbHg56zS2uxw

- Desktop frame: 3:16. Mobile frame: 3:51. Primary-action component: 3:14.
- Charcoal canvas #0e1012, panel #171a1d, black sidebar #050606, lime action #c8f582.
- Each workspace destination shows one activity. Hash links preserve browser back/forward navigation and direct links.
- Lessons group content into Read the code, Understand it, and Try it yourself. Persistent navigation keeps the next step available.
- Desktop music stays in the bottom-left sidebar. On mobile it is inside Menu so it cannot cover a lesson.
- Figma uses Inter, because the source Segoe UI font was unavailable there. The website prefers locally installed Inter, with Segoe UI/system fallbacks; it does not fetch external fonts. Typography can differ slightly by device.
- The Figma views document the reading layout, not a complete interactive prototype. The implementation retains all original lesson explanations, quizzes, hints, glossary, saved work, and native audio controls.

Figma evidence: editable text and auto-layout frames, two action instances, no image-filled UI layers. Color and spacing variables and body text style are local to this file. No Code Connect mappings existed in the source.
